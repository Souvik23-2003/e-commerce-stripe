# E-Commerce Website with Stripe

A full-stack e-commerce website built using HTML, CSS, JavaScript, Node.js, Express.js and Stripe.

## Features

- Product listing
- Product details page
- Shopping cart
- Add/remove products
- Order summary
- Stripe test payment integration
- Payment success page
- Admin order history
- View/Hide order details
- INR currency support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Stripe
- Tailwind CSS
- JSON
- Git & GitHub
